# ImageProcessingProject
#### [a simple image processing program]

### 개요
- 이전 회사에서 과제로 진행 했던 영상처리 프로그램을 구현
- java(spring) 또는 python(django)를 이용하여 구현(학습 목적)
- 이전에 c++(mfc)와 c#(winform)으로 구현 했던 것을 웹 환경에서 구현

### 목적
- 이전에 알고 있었던 지식들을 복기하고, spring, django 등 필요 지식들을 학습.
- 앞으로 프로젝트 진행을 위한 초석을 마련(연습 목적)

### 구현 내용
- 이전에 과제로 진행했던 내용을 구현
  - 이미지 열기 및 저장
  - 이미지 확대 및 축소
  - 확대된 이미지에서 보여지는 부분 이동
  - 침식/팽창 연산 **
  - 라벨링
  - 히스토그램 평활화 
  - 오츠이진화
  - 가우스 필터 **
  - 라플라스 필터
  - FFT 필터
  - 템플릿 매칭 **
  - ** : 연산을 SSE(Streaming SIMD Extensions)로 구현
  - 단 과거 구현하지 못했던 부분을 구현하거나 과거 구현했지만 프로젝트 진행 중 불필요하게 느껴지는 기능의 경우 생략 가능

### 추후 계획
- 현재 진행하는 프로그램은 학습 목적으로 단순히 기능만 구현하는 프로그램이다. 따라서 기능을 구현 후 영상처리를 활용할 수 있는 분야를 찾아서 새로운 프로그램으로 발전시킨다.

### 프로젝트 기획 수정 - 2025_10_01
- 기존에 기획했던 것을 학습 효과 및 활용성을 높이기 위해 수정
- 본격적인 프로젝트 진행에 앞서서 기존에 기능만 구현하려고 했던 프로젝트를 좀 더 유용한 프로그램으로 구현
- 영상 처리 기술을 활용하여 카드 및 신분증 인식 프로그램을 구현할 예정
- Python Django 프레임워크 이용, OpenCv 라이브러리 이용(일부 기능 직접 구현 - pillow 및 numpy 사용)
- 필요 기능 :
  - 로그인 및 회원가입 기능
  - 사용자 정보 저장
  - 이미지 등록 및 저장
  - 영상 인식 및 영상으로 부터 얻은 정보 저장
